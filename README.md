# S-AES
Código feito para disciplina de Tópicos avançados em computadores 2025.1 (UnB)

Como usar:
 - Parte 1 -- usar o arquivo SAES.py. Ele já faz o teste com a string 'ok', e mostra os resultados em hexa e em b64;
 - Parte 2 -- usar o arquivo SAES_ECB.py. Ele já faz o teste com uma string maior, com repetição para poder verificar se esse modo de operação realmente repete os blocos como é previsto;
 - Parte 3 -- usar o arquivo AES_types.py. Ele possui o teste dos modos de operação pedidos e mostra a comparação de tempo e execução de cada modo no final;

Obs.: Na parte 3 não fiz a comparação de aleatoriedade.
